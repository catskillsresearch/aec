# Strict slot

From [§3.2 The orbit record of a short sequence](3.2.md).

For a subset $A$ of a linear order $L$ and a cut $A = A^- \sqcup A^+$, including cuts with an empty side, define its strict slot by

$$S_L(A^-, A^+) = \{x \in L \setminus A : A^- < x < A^+\}.$$
