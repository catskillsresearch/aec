# Lemma 4.7

Lemma 4.7 (Ordinal-vector witnesses). Let $C$ be a set, and let $U$ be a definable class of functions $C \to \mathrm{Ord}$, with fixed set parameters allowed in its definition. There is a set $U_0 \subseteq U$ such that each $u \in U$ dominates some $v \in U_0$ coordinatewise.
