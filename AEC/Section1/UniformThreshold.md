# Uniform threshold

From [Theorem 1.2](Theorem_1.2.md).

Theorem 1.2 (Uniform eventual categoricity). For every infinite cardinal $\lambda$ there is a cardinal $\mu(\lambda) \ge \lambda$ such that the following holds for every AEC $K$ with $\mathrm{LS}(K) \le \lambda$:

$$(\exists \kappa \ge \mu(\lambda)\ \ K\text{ is categorical in }\kappa) \implies (\forall \kappa' \ge \mu(\lambda)\ \ K\text{ is categorical in }\kappa').$$

The same threshold is used in the premise and the conclusion.
