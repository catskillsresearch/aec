# Eligible level

From [Convention 5.1](Convention_5.1.md).

Convention 5.1 (Closure below a level). An eligible level is an infinite cardinal belonging to the class of cardinals on which the particular construction under consideration has been established. Except when explicitly discussing preliminary levels, we use strong limit levels of countable cofinality.
