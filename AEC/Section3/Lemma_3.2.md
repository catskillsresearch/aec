# Lemma 3.2

Lemma 3.2. The order $H(\delta)$ is dense without endpoints and has cardinality $|\delta|$. Its points have character $\mathrm{cf}(\delta)$ on both sides. All nonempty bounded open intervals have one order type. All left rays have one order type, and all right rays have one order type. An increasing map between ordinal position sets induces an order embedding between the corresponding $\Gamma$ and $H$ orders by moving positions and padding by zero. Each point of $H(\delta)$ has a code using finitely many ordinal positions and integer and rational coefficients; comparisons are determined by these discrete coefficients and the order/equality pattern of the ordinal positions.
