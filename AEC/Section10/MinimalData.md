# Minimal type

From [Proposition 10.2](Proposition_10.2.md).

Proposition 10.2 (A minimal type). There is a sufficiently closed single-model level $\lambda_0$, a model $M_0 \in K$ of size $\lambda_0$, and a nonalgebraic singleton type $p_0$ over $M_0$ such that, over every $M_0 \le_K A \in K$ of size $\lambda_0$, there is exactly one nonalgebraic extension of $p_0$. This extension is its free lift.
