# Eligible subclass

From [Convention 5.3](Convention_5.3.md).

Convention 5.3 (Supply of eligible levels). For the generic scheme refinements below, we use the following eligible-subclass hypothesis whenever an unbounded class of refined levels is asserted. The input eligible class $S$ must contain a fixed definable unbounded subclass $T$ closed under suprema of strictly increasing countable sequences. In addition to the input scheme's individual conditions, this is a hypothesis on the supply of eligible levels; arbitrary unboundedness of $S$ does not imply it.
