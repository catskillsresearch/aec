# Adequacy

From [13.1 Set definitions at a given cardinal](13.1.md).

There are only finitely many forms in this menu. The geometric categoricity and basis item can be used before the diagram clause has been obtained for the current geometric shape. A descriptor records which assertions are currently required, and for which finitely many lower descriptors. Bounded quantification over that finite record yields one formula, denoted $\mathrm{Adeq}(d, \mu)$. Its ingredients were all defined by set operations or by the fixed underlying $K$ and $D_F$ formulas.
